# BoBoiBoy Universe Portal

A pure HTML5 and CSS3 multi-page web portal dedicated to the BoBoiBoy franchise, featuring characters, 7 elemental powers, chronicles timeline, and a cadet enlistment dispatch terminal.

## Pages & Structure
- `index.html` - Master Frame Portal with fixed header navigation
- `home.html` - Overview, origin lore, and featured vanguard
- `characters.html` - Character dossiers with stats and profiles
- `elements.html` - 7 Elemental powers and combat tactical matrix
- `series.html` - Chronicles timeline, release table, and watch order
- `contact.html` - Cadet enlistment form with 7 form controls and FAQ
- `main.html` - Default content frame source
- `frameset.html` & `nav.html` - Alternative traditional frameset structure
- `css/style.css` - Responsive layout styles
- `images/` - Visual assets and character posters

## Getting Started
Open `index.html` in any modern web browser.
