# BoBoiBoy Universe Portal

A clean, responsive HTML5 and CSS3 multi-page web portal dedicated to the BoBoiBoy franchise, featuring characters, 7 elemental powers, chronicles timeline, and a cadet enlistment dispatch terminal.

## Project Structure
- `index.html` - Galactic Home Portal with hero showcase and embedded mission radar
- `characters.html` - Character dossiers with combat stats and TAPOPS guardian profiles
- `elements.html` - 7 Elemental powers, 3 evolutionary tiers, and combat matrix
- `series.html` - Series & movies chronicles timeline and release table
- `contact.html` - Cadet enlistment dispatch form with full HTML5 controls and FAQ
- `css/style.css` - Responsive layout and elemental theme styles
- `images/` - Visual assets, emblems, and character renders

## Getting Started
Open `index.html` in any modern web browser.
