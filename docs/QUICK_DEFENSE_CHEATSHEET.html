2-Minute Code Defense Cheat Sheet

Web Programming Project 1 • BoBoiBoy Universe Portal • Resident University
1. 100% Alignment with Lecture PPTs (Weeks 1 to 6)
Dosen tanya: "Apakah kodingan ini sesuai dengan materi yang diajarkan di kelas / PPT?"
Jawaban: "Yes. 100% of our code strictly follows the course PPTs from Week 1 to Week 6: PPT 01 (semantic HTML & lists), PPT 02 (media & tables), PPT 03 (frames & 7-control form), PPT 04 (3 CSS methods & selectors), PPT 05 (4 CSS property categories), and PPT 06 (RWD box-sizing & media queries). No external libraries or complex frameworks were used."
2. Master Frame Architecture (index.html)
Dosen tanya: "Gimana cara kerja website ini?"
Jawaban: "This website uses a Master Frame architecture taught in PPT 03. The navbar is written once in index.html, and content loads inside the <iframe name='mainFrame'> using target='mainFrame' without refreshing the outer navbar."
3. The 5 Interconnected Pages (All Under 200 Lines)
Dosen tanya: "Ada berapa halaman dan fungsinya apa saja?"
Jawaban: "We have 5 interconnected pages kept concise under 200 lines each: home.html (179 lines), characters.html (190 lines), elements.html (193 lines), series.html (160 lines), and contact.html (196 lines)."
4. Three Methods of Using CSS (PPT 04)
Dosen tanya: "Di mana 3 cara pakai CSS-nya?"
Jawaban: "1. External CSS in css/style.css for global styles, 2. Internal CSS in <style> tags in <head> for page components, and 3. Inline CSS in style='...' attributes for micro-spacing and specific widths."
5. Four Required CSS Property Categories (PPT 05)
Dosen tanya: "Sebutkan 4 kategori CSS yang wajib di rubrik!"
Jawaban: "1. Background (color, image, position, repeat, size), 2. Text/Font (family, size, weight, line-height, color), 3. Dimensions (width, min-width, max-width, height, min-height), and 4. Positioning (position, top, bottom, left, right, z-index)."
6. Form & Semantic Validation (contact.html - PPT 03)
Dosen tanya: "Formulirnya ada apa saja dan validasinya pakai apa?"
Jawaban: "The Cadet Enlistment Form has all 7 required controls from PPT 03 (text, password, textarea, radio, checkbox, select, submit). Validation is handled purely with HTML5 attributes like required, placeholder, and minlength='8' with zero JavaScript."
7. Clean Box Model & Responsive Design (PPT 06)
Dosen tanya: "Bagaimana penerapan responsive web design-nya?"
Jawaban: "We used standard CSS Box Model spacing with universal * { box-sizing: border-box; }, viewport meta tag, and CSS Media Queries (@media (max-width: 768px)) as taught in PPT 06."
